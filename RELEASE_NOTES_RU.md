# VK Likes Cleaner v0.2.6 — Stable

**VK Likes Cleaner** — Chromium-расширение для управления **собственными реакциями во ВКонтакте** (`vk.com` и `vk.ru`).

Версия **v0.2.6** проверена пользователем на реальном ВК. Дополнительно пройдено **1 516 офлайн-проверок** (background: 1259, content: 239, dashboard: 18).

## Возможности

- Ручные порции по **1 / 3 / 10 / 25** попыток с задержками между действиями.
- Режим **«∞ · До конца выбранного раздела»** с автопрокруткой, небольшими внутренними порциями и остановкой после исчерпания доступной ленты.
- **Пауза**, **Продолжить** и **Остановить** для управления процессом.
- Обнаружение типовых проверок **«Я не робот» / CAPTCHA** с прекращением обработки. Проходить CAPTCHA нужно **вручную**.
- Локальная статистика и отчёт о результатах. «Вероятно снято» — не серверное подтверждение.

## Установка

1. Скачайте **`VK_Likes_Cleaner_v0.2.6_Chromium.zip`** из приложенных файлов релиза.
2. Распакуйте ZIP в постоянную папку.
3. В Chromium-браузере откройте `chrome://extensions/` (в Яндекс Браузере можно использовать `browser://extensions/`), включите режим разработчика.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с `manifest.json`.
5. Откройте свой аккаунт ВК, обновите вкладку и запустите небольшую пробную порцию.

## Важно

- Автоматизация предназначена **только для собственных реакций**. Удаление реакций нельзя отменить одной кнопкой.
- Режим «До конца» не гарантирует очистку всех исторических реакций — только доступной части выбранного раздела.
- При CAPTCHA, ограничении скорости или неожиданном поведении **остановите обработку**. Расширение не решает и не обходит проверку.
- Разрешение Chromium `debugger` технически широкое, несмотря на то что код применяет его к вкладкам ВК.
- Проект **не связан с администрацией ВКонтакте** и не одобрен ею.
